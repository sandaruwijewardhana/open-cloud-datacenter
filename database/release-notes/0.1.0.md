DBaaS v0.1.0 is the first release: managed PostgreSQL on Harvester, with each database in its own virtual machine. It has two parts:

- **Operator**: runs on the Harvester cluster as an Addon and manages `DBInstance`, `DBSnapshot` and `DBRestore` resources. The API is `dbaas.opencloud.wso2.com/v1alpha1` and may change in later releases.
- **Rancher UI extension**: create and run databases from Rancher, including snapshots, restores, OS updates and database images.

## Requirements

- Harvester 1.9.0 (the tested version), with Rancher Monitoring enabled. The operator creates a `ServiceMonitor` for every database.
- A VLAN network that gives database VMs internet access on first boot.
- The database VM images below.
- For the UI extension: Rancher 2.15 or later (tested on 2.15.2).

## Database VM images

The operator does not download images. Build them with Packer (`database/images/packer`) and upload them to the Harvester `default` namespace with exactly these names. Admins can also upload them from the UI's **Database Images** page.

| Image | Ubuntu | PostgreSQL |
| --- | --- | --- |
| `ubuntu-2204-postgres-v20260515` | 22.04 (default) | 15, 16, 17 |
| `ubuntu-2404-postgres-v20260701` | 24.04 | 15, 16, 17, 18 |

## Install

1. Upload the database VM images.
2. On the Harvester cluster, apply the attached Addon manifest: `kubectl apply -f dbaas-operator-addon.yaml`. Check it with `kubectl get addon dbaas-operator -n dbaas-system`.
3. In Rancher, as an admin: **Extensions** → ⋮ → **Manage Extension Catalogs** → **Import Extension Catalog**, using the UI extension image listed under Artifacts. Then install **DBaaS** from the **Available** tab.

For details, upgrades and uninstalling, see `database/INSTALL.md`.

## Known limitations

- VLAN networks only. Overlay (Kube-OVN) networks are not supported.
- After an instance class change, `max_connections` keeps its old value until the next OS update (repave).
- Prometheus can scrape PostgreSQL metrics only if the cluster's pod network can reach the database VLAN.
- The UI offers only the operator's default instance classes and PostgreSQL versions.
